# 🚀 UNLIMITED RUSH — 360° Космическая Гонка в Трубе

> Футуристическая 3D аркада в бесконечном неоновом цилиндре на движке Three.js + React + Express с поддержкой PWA (Android, iOS, ПК), глобальным лидербордом и эпической битвой с боссом-дредноутом «Архитектор Бездны».

---

## 📱 Установка как приложение (PWA)

Игра поддерживает полноценный стандарт **Progressive Web App (PWA)** с оффлайн-кэшированием и запуском в полноэкранном режиме:

### 🤖 Android (Chrome / Yandex Browser / Edge)
1. Откройте сайт игры в браузере.
2. В главном меню игры нажмите фиолетовую кнопку **«УСТАНОВИТЬ ПРИЛОЖЕНИЕ (PWA)»** (или в меню браузера выберите *«Добавить на главный экран»* / *«Установить приложение»*).
3. Игра появится на рабочем столе вашего смартфона как отдельное нативное приложение с собственной иконкой и плавным 60/120 FPS геймплеем.

### 🍏 iPhone / iPad (iOS Safari)
1. Откройте сайт игры в браузере **Safari**.
2. В нижней панели Safari нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх $\uparrow$).
3. Пролистайте вниз и выберите **«На экран "Домой"»** (Add to Home Screen).
4. Нажмите **«Добавить»**. Игра запустится без адресной строки браузера во весь экран.

### 💻 ПК (Chrome, Edge, Opera, Yandex)
- В адресной строке нажмите значок монитора со стрелкой или кнопку в главном меню для установки на рабочий стол Windows / macOS / Linux.

## 🍏 Особенности iOS PWA при размещении в подпапке (/rush/)

Если игра размещена в подкаталоге (например, `https://game.dalazareva.ru/rush/`), Safari на iOS предъявляет строгие требования к Web App Manifest:
1. **Scope и Start URL:** В `dist/manifest.webmanifest` пути `id`, `start_url` и `scope` зафиксированы на `/rush/`. При использовании относительного `./` Safari в диалоге «На экран Домой» обрезал путь до корневого домена `https://game.dalazareva.ru/`, из-за чего иконка вела на пустой корень и открывала черный экран.
2. **Иконка Apple Touch Icon:** В `index.html` прописан абсолютный путь `/rush/apple-touch-icon.png` с атрибутом `sizes="180x180"`, благодаря чему на экране «Домой» отображается фирменная неоновая кибер-иконка игры вместо серой буквы "U".
3. **Обновление ярлыка на iPhone:** 
   - Обязательно **удалите старый ярлык** игры с рабочего стола iPhone (долгий тап по иконке ➔ *Удалить закладку*).
   - В Safari откройте именно `https://game.dalazareva.ru/rush/` (с косой чертой на конце).
   - Нажмите *«Поделиться»* ➔ *«На экран „Домой“»* (в диалоге будет указан URL `/rush/` и правильная цветная иконка) ➔ *«Добавить»*.
4. **Рекомендация для Хаба (`https://game.dalazareva.ru/`):**
   В файле главного меню/хаба добавьте автоматический редирект в standalone-режиме:
   ```html
   <script>
     if (window.navigator.standalone || window.matchMedia('(display-mode: standalone)').matches) {
       window.location.replace('/rush/');
     }
   </script>
   ```
   Это гарантирует, что если игрок случайно запустит приложение из корня, он мгновенно будет перенаправлен в игру.

## 🖥️ Развертывание на сервере (VPS / Cloud)

### Вариант 1: Развертывание через Docker (Рекомендуется)
На вашем сервере должен быть установлен Docker и Docker Compose.

```bash
# 1. Клонируйте репозиторий на сервер
git clone https://github.com/ВАШ_АККАУНТ/unlimited-rush.git
cd unlimited-rush

# 2. Запустите контейнер в фоновом режиме
docker compose up -d --build

# Приложение готово и работает на http://IP_ВАШЕГО_СЕРВЕРА:3000
```
*Примечание: папка `./data` монтируется как том, поэтому ваши рекорды в лидерборде и облачные сохранения игроков сохранятся даже при обновлении или перезапуске контейнера.*

---

### Вариант 2: Запуск через Node.js и PM2
На сервере установлен Node.js 18+ и npm.

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/ВАШ_АККАУНТ/unlimited-rush.git
cd unlimited-rush

# 2. Установите зависимости
npm install

# 3. Соберите клиент и сервер
npm run build

# 4. Запустите через PM2 (для автоперезапуска и работы в фоне)
npm install -g pm2
pm2 start dist/server.cjs --name "unlimited-rush"
pm2 save
pm2 startup

# Игра доступна на порту 3000!
```

## 🌐 Настройка Nginx при размещении игры в подпапке (напр. https://game.dalazareva.ru/rush/)

Если у вас на основном домене `https://game.dalazareva.ru/` находится **Хаб игр**, а эта игра развернута по пути `/rush/`, добавьте следующий блок в конфигурацию вашего виртуального хоста Nginx (обычно `/etc/nginx/sites-available/...`):

```nginx
# Конфигурация для игры Unlimited Rush в подпапке /rush/
location /rush/ {
    proxy_pass http://127.0.0.1:3000/;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection 'upgrade';
    proxy_set_header Host $host;
    proxy_cache_bypass $http_upgrade;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

> **Важно:** Обратите внимание на завершающий слэш в `proxy_pass http://127.0.0.1:3000/;`! Он сообщает Nginx срезать префикс `/rush/` при передаче запроса в сервер приложения, либо вы можете использовать без слэша — игра теперь аппаратно поддерживает оба варианта маршрутизации как по корню, так и по `/rush/`.

После изменения конфига Nginx выполните:
```bash
sudo nginx -t && sudo systemctl reload nginx
```

## 🏆 Система лидерборда и API

В игру встроен быстрый и надежный backend API для учета рекордов и облачных сохранений:
- **`GET /api/leaderboard?mode=survival`** — получение топ-50 рекордов для выбранного режима.
- **`POST /api/leaderboard/submit`** — отправка результата заезда (дистанция, время, корабль, имя пилота). Возвращает занятое место в таблице.
- **`POST /api/cloud/save`** & **`GET /api/cloud/load/:syncKey`** — кроссплатформенная синхронизация прогресса (гараж, монеты, скрап).
- **Постоянное хранение:** результаты сохраняются в файле `data/leaderboard.json` на сервере.

## 🎮 Управление в игре

- **Клавиатура (ПК):**
  - `A` / `D` или `←` / `→` — орбитальное вращение по цилиндру (360°).
  - `W` / `↑` / `Shift` — Форсаж (Boost).
  - `Пробел` — Экстренное торможение / Замедление времени.
  - `R` — Быстрый перезапуск.
  - `Esc` — Пауза.

- **Сенсорные экраны (Смартфоны / Планшеты):**
  - **Свайп 360° (По умолчанию):** плавное горизонтальное скольжение пальцем по экрану для точного управления траекторией вокруг трубы.
  - **Кнопки со стрелками:** классическая раскладка виртуальных кнопок влево/вправо.
  - Настраиваемая чувствительность от 40% до 220% в меню опций.
